FRONTEND QUALITY GATE

Every UI implementation must pass a visual review before being
considered complete.

Reject the implementation if it contains:

- generic AI/SaaS visual patterns
- centered-by-default layouts
- oversized headings
- excessive cards
- excessive rounded corners
- unnecessary gradients
- decorative gradients or glow effects
- excessive whitespace
- visually repetitive sections
- arbitrary icons used as decoration
- inconsistent spacing
- weak information hierarchy
- unnecessary animations
- components created only to make the page look "modern"

Prefer:

- strong information hierarchy
- intentional alignment
- asymmetric layouts when appropriate
- appropriate information density
- restrained color usage
- functional whitespace
- clear navigation
- meaningful grouping
- tables/lists for structured data
- consistent spacing
- deliberate typography
- subtle interaction feedback

The UI must look like a mature developer product, not an
AI-generated SaaS template.
